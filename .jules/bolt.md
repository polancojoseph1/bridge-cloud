## 2024-05-15 - Memoize AgentRow in ProviderSelector
**Learning:** Frequent polling of agent health in `ProviderSelector` via `useAgentHealth` causes the parent component to re-render constantly. Because `AgentRow` uses inline functions for `onSelect` when rendering mapped array elements, this forces React to needlessly re-render every `AgentRow` child component on every health poll update, creating cascading O(N) rendering overhead.
**Action:** When child components are rendered in lists within parents that update frequently (like polling components), wrap the child list items (`AgentRow`) in `React.memo()`. For the memoization to work effectively, ensure the parent provides stable function references (using `useCallback`) or have the child accept a primitive identifier and invoke the handler with it.
