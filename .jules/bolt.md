## 2024-10-17 - React.memo() Pitfall with Polling Hooks
**Learning:** Polling hooks like `useAgentHealth` that map and return an array cause frequent re-renders in their consumers. We previously memoized the array inside the hook using `useMemo` to keep reference stable between state updates. However, components like `ProviderSelector` still map that array to child elements (like `AgentRow`) *every single time the hook state updates* (which happens during every polling cycle due to `setStatus(cachedStatus)`). If the child elements aren't memoized with `React.memo`, this results in O(N) child component re-renders every 30 seconds for all agents, even those whose health hasn't changed.
**Action:** When a parent frequently re-renders due to background polling state updates, always wrap mapped child components in `React.memo()`. Provide primitive values or stable `useCallback` references for callback props to ensure the memoization isn't defeated.
