## 2025-02-23 - URL Normalization Bypassing IPv6 SSRF Protection
**Vulnerability:** Node.js's built-in `URL` module normalizes IPv4-compatible IPv6 addresses (e.g. `::127.0.0.1` or `0:0:0:0:0:0:127.0.0.1`) into their pure hex representations (`::7f00:1`). Standard string-matching filters or IP parsing checks that expect the literal dot-decimal format or IPv4-mapped format (`::ffff:`) fail to detect these normalized forms, allowing attackers to access internal/loopback services by supplying an IPv4-compatible IPv6 payload.
**Learning:** Normalizing user-supplied URLs *before* extracting the IP or hostname causes certain IPv6 formats to be compressed or converted into hex formats that bypass simple subnet string matching logic.
**Prevention:** When validating IP addresses to prevent SSRF, especially after URL parsing/normalization, ensure that the validation logic explicitly handles compressed or normalized hex equivalents of forbidden subnets (e.g., verifying that `::7f00:1` properly flags as the `127.0.0.0/8` subnet), rather than just checking for literal strings like `127.0.0.1` or `::ffff:`.
