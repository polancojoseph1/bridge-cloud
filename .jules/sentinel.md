## 2024-05-30 - Fix SSRF filter bypass via IP obfuscation
**Vulnerability:** The `isForbiddenHostname` SSRF protection blocklist failed to normalize obfuscated IP formats such as octal (e.g., 0177.0.0.1) or IPv4-mapped/IPv4-compatible IPv6 addresses (e.g., ::ffff:127.0.0.1 or ::127.0.0.1). This allowed malicious requests to reach internal subnets by bypassing the explicit blocklist.
**Learning:** We can rely on the native, WHATWG-compliant `new URL()` constructor to automatically normalize and decode obfuscated IPv4 addresses and many IPv6 variations into standard, consistent formats. However, IPv4-mapped and IPv4-compatible IPv6 addresses are normalized into pure hex blocks (e.g., ::ffff:7f00:1) by Node.js, so specific validation parsing must be added for these hex blocks to extract the underlying 32-bit IPv4 address correctly.
**Prevention:** Always normalize incoming URLs and hostnames using native `URL` parsers before attempting string-based blocklist checks. Be aware of how language-specific parsers normalize edge cases (like mapped IPv6) and write targeted validators against the normalized output.
