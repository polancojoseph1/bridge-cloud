## 2024-05-24 - [CRITICAL] Fix SSRF filter bypass with IPv4 mapped IPv6 and hex formats
**Vulnerability:** Node.js URL normalization for fetch automatically transforms dot-decimal IPv4-compatible (::192.168.1.1) and IPv4-mapped (::ffff:192.168.1.1) IPv6 addresses into hex-encoded formats like `::c0a8:101`. The existing blocklist matched literal IP strings and only prefixes like `::ffff:`, which bypassed the filter because `isForbiddenHostname` only saw `::c0a8:101` when requests were made without `::ffff:`.
**Learning:** Checking strictly against prefix matches or explicit dot-decimal notations for IPv4-compatible/IPv4-mapped addresses fails when standard underlying HTTP or DNS libraries automatically convert these into hex chunks. The payload embedded inside the IPv6 address needs to be actively extracted and checked.
**Prevention:** Normalize and extract embedded IPv4 addresses from mapped/compatible IPv6 formats to validate them against existing IPv4 blocklists. Ensure hex-encoded segments (e.g. `c0a8:101`) are unrolled and checked against standard restrictions.
