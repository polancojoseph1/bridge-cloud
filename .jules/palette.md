## 2026-10-17 - Add Explanatory Titles to Disabled Buttons
**Learning:** Disabled buttons without an explanation can confuse users on why an action is unavailable. Using `title` tooltips on these elements is a lightweight pattern to provide inline guidance and improve accessibility without cluttering the UI.
**Action:** When creating form validation or context-dependent buttons that can be disabled, always add a `title` or `aria-description` providing actionable context on how to enable the action.
