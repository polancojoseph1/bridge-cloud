## 2024-05-18 - Missing Tooltips on Dynamic Icon-Only Buttons
**Learning:** Found that while some icon-only buttons (like `SendButton`) had tooltips, dynamic tabs (like desktop instance tabs) had an `aria-label` for screen readers but lacked a `title` attribute for native tooltips, leaving sighted mouse users without context for standard UI icons. Also found that `title` attributes on a custom Button component can conflict with standard JSX props if redefined or duplicated.
**Action:** When adding or verifying icon-only interactive elements inside mapping loops (like tabs or lists), ensure both `aria-label` and `title` are present and dynamically match the context (e.g., `title={"Close " + instance.label}`). When working on custom UI components, ensure `title` isn't accidentally passed twice in the JSX.
